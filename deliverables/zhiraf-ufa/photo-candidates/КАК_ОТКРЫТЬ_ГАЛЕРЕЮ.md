# Как открыть галерею с фотографиями (если «не открывается»)

## Что **нельзя** делать

- **Не** открывайте в браузере ссылку вида  
  `https://raw.githubusercontent.com/.../pexels-resorts-table-gallery.html`  
  браузер покажет **код файла**, а не страницу с картинками.

## Способ 1 — без git (ZIP)

1. Скачайте архив ветки с работой (целиком репозиторий в одном архиве):  
   https://github.com/yakhinr76-oss/teya-cursor-plugin/archive/refs/heads/cursor/pexels-resorts-table-51c9.zip  

2. Распакуйте архив в любую папку.

3. Откройте **проводником** файл (двойной клик):  
   `teya-cursor-plugin-cursor-pexels-resorts-table-51c9/deliverables/zhiraf-ufa/photo-candidates/pexels-resorts-table-gallery.html`  

   Имя корневой папки после распаковки может немного отличаться — главное дойти до папки `photo-candidates` и открыть **`pexels-resorts-table-gallery.html`**.

## Способ 2 — мини-сервер (если в браузере пустая страница или не грузятся картинки)

В папке `photo-candidates` выполните в терминале:

```bash
cd путь/к/photo-candidates
python3 -m http.server 8765 --bind 127.0.0.1
```

В браузере откройте: **http://127.0.0.1:8765/pexels-resorts-table-gallery.html**

Остановить сервер: `Ctrl+C` в том же окне терминала.

## Способ 3 — из Cursor / VS Code

1. В боковой панели найдите файл `pexels-resorts-table-gallery.html`.
2. ПКМ по файлу → **Reveal in File Explorer** (Показать в проводнике).
3. Дважды щёлкните по файлу — откроется браузер по умолчанию.

## Если всё равно не работает

1. Откройте страницу как в способе 1 или 2.
2. Нажмите **F12** → вкладка **Console** (Консоль).
3. Скопируйте **красные** сообщения об ошибках и пришлите их — по ним можно понять причину (блокировка сети, старый браузер и т.д.).

Файл со списком ссылок на все кадры по-прежнему: `pexels-resorts-table-picks.md`.
