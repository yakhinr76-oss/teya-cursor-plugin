## Хаб направлений (2 варианта на карточку «Актуальные предложения»)

## Одна ссылка — вставьте в **адресную строку браузера** (Chrome, Safari, Яндекс…)

**Не** кликайте по файлу в Cursor и **не** открывайте страницу файла на GitHub — там будет код.

1. Скопируйте **целиком** эту ссылку:  
   https://htmlpreview.github.io/?https://raw.githubusercontent.com/yakhinr76-oss/teya-cursor-plugin/cursor/pexels-resorts-table-51c9/deliverables/zhiraf-ufa/photo-candidates/index.html  

2. Вставьте в **адресную строку** обычного браузера (туда, где обычно `google.com`), нажмите Enter.

3. Должны появиться **фото**; листайте вниз.

## Почему в Cursor виден **код**, а не картинки

Если вы **щёлкаете по `.html` в боковой панели Cursor** (или по ссылке на GitHub `raw.githubusercontent.com`), откроется **текст файла**, а не страница в браузере. Так и задумано в редакторе.

### Способ А — кнопка **Publish** в этом чате агента (самый простой)

В ответе агента должна быть кнопка **Publish** / превью приложения. Нажмите её, подтвердите публикацию (лучше **Public**, чтобы открыть в обычном браузере без логина) — откроется **живая страница с картинками**.

### Способ Б — открыть в браузере с диска

1. В Cursor: **ПКМ** по файлу `index.html` (папка `photo-candidates`) → **Reveal in File Explorer** / **Открыть содержащую папку**.
2. **Двойной клик** по `index.html` в проводнике — откроется браузер по умолчанию.

Тот же результат дают файлы:

- `index.html` — **главный** (вся галерея сразу)
- `hub-candidates.html` — то же самое, латинское имя (удобно, если кириллица в пути мешает)
- `СМОТРЕТЬ_КАНДИДАТЫ_ХАБ.html` — копия галереи

### Способ В — Simple Browser в Cursor

1. `Ctrl+Shift+P` (или `Cmd+Shift+P` на Mac) → команда **Simple Browser: Show**.
2. Вставьте путь к файлу или локальный URL с мини-сервером (способ Г).

### Способ Г — мини-сервер (если картинки не грузятся)

В папке `photo-candidates`:

```bash
cd путь/к/photo-candidates
python3 -m http.server 8765 --bind 127.0.0.1
```

В браузере: **http://127.0.0.1:8765/** (откроется `index.html` с галереей).

Остановить: `Ctrl+C` в терминале.

## Что **нельзя** делать

- **Не** открывайте в браузере ссылку вида  
  `https://raw.githubusercontent.com/.../index.html`  
  — браузер покажет **код**, а не страницу.

## Способ без git (ZIP)

1. Скачайте архив ветки:  
   https://github.com/yakhinr76-oss/teya-cursor-plugin/archive/refs/heads/cursor/pexels-resorts-table-51c9.zip  

2. Распакуйте, откройте в проводнике:  
   `.../deliverables/zhiraf-ufa/photo-candidates/index.html` (двойной клик).

## Если всё равно не работает

1. Откройте страницу способом Б или Г.
2. **F12** → **Console** → скопируйте красные ошибки и пришлите в чат.

Файл со списком ссылок: `pexels-hub-direction-candidates.md`.
