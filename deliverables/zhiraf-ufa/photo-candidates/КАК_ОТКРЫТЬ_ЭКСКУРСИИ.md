# Галерея кандидатов — экскурсии (Грузия, Узбекистан, Армения)

## Способ 1 — двойной клик (Windows)

1. Обновите репо: ветка **`cursor/excursion-program-photos-7ec1`** (или `main`, если уже смержили PR #151).
2. Откройте в Проводнике (не в Cursor как текст):

`deliverables\zhiraf-ufa\wp-theme\zhiraf-ufa\assets\img\excursions\candidates\index.html`

3. Двойной клик → откроется в Chrome/Edge с **картинками**.

Фото лежат в подпапках `gruziya\`, `uzbekistan\`, `armeniya\`.

---

## Способ 2 — ссылка в браузере (без локального клона)

Вставьте **целиком** в адресную строку (после merge ветки в GitHub):

https://htmlpreview.github.io/?https://raw.githubusercontent.com/yakhinr76-oss/teya-cursor-plugin/cursor/excursion-program-photos-7ec1/deliverables/zhiraf-ufa/wp-theme/zhiraf-ufa/assets/img/excursions/candidates/index.html

Если страница пустая — на `main` ещё нет папки с JPEG; переключите ветку в ссылке или сделайте `git pull`.

## Почему «не открывается»

| Что делаете | Что видите |
|-------------|------------|
| Клик по `.html` в Cursor | Код, без фото |
| GitHub → Raw | Текст, без фото |
| `scripts/preview_excursion_photos.html` без pull | Битые ссылки |
| Ветка `main` без PR #151 | Нет файлов на диске |

Пересобрать только галерею (картинки уже скачаны):

`python3 scripts/fetch_excursion_photos.py --preview-only`
