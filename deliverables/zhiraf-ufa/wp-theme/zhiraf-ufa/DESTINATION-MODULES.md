# Центральные модули лендингов направлений

Под блоком каталога туров на каждой странице `/tour/{slug}/` показывается **один** интерактивный модуль.

| Модуль | Назначение |
|--------|------------|
| `battle` | VS двух курортов + CTA в WhatsApp |
| `season` | Табы сезонов / климата + квиз «Подобрать на эти даты» |
| `vibe` | 4 карточки сценария → квиз с prefill |

## Дефолты (можно переопределить в WP: метабокс «Тип блока»)

| Направление | Модуль |
|-------------|--------|
| Турция, Египет, Таиланд, Абхазия | battle |
| Турция | + блок vibe после battle (`vibes_after_central`) |
| ОАЭ, Вьетнам, Шри-Ланка | season |
| Россия, Узбекистан, Армения | vibe |
| Китай, Индия, Индонезия, Мальдивы, Сейшелы | battle (Москва) |

Конфиг: `inc/destination-landing-config.php` → `zhiraf_ufa_destination_default_module_map()`.
