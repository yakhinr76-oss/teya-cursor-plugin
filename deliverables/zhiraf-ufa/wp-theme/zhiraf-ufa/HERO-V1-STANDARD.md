# Hero v1 — единый стандарт посадочных направлений

Применяется к curated-хабам `/tour/{slug}/` (Турция, Египет, ОАЭ, Таиланд, Мальдивы, Вьетнам и все новые страны).

## Копирайтинг

### Первый абзац (`hero_lead`)

- **Не начинать** со штампа «Отобрали 6 проверенных…» — это не SEO-якорь.
- **Начинать** с коммерческого запроса: «Пакетные туры / путёвки в [страну] из Уфы…».
- Включать LSI: «всё включено», прямой рейс / чартер / перелёт с багажом, «цены за двоих», названия главных курортов.
- **Не ссылаться на статьи блога** из Hero (сравнения — только в блоке «Полезные гиды»).

### Запрещённый сленг (в Hero, бейджах, чипах каталога)

| Нельзя | Пишем |
|--------|--------|
| BB, HB, AI, UAI | на завтраках, полупансион, «Всё включено», «Ультра всё включено» |
| РАК | Рас-эль-Хайма |
| Сев. Мале, Юж. Ари | Северный Мале, Южный Ари |
| «резорты» (Мальдивы) | островные отели, отели и виллы |

Допускается **Adults Only** как устоявшийся термин рынка.

## Бейджи Hero (`hero_badges`)

Ровно **два** бейджа в ряд на десктопе:

1. Перелёт (факт из полётной программы БГ / чартеры).
2. Виза / въезд (`icon_svg` => `passport` — SVG, не эмодзи пальмы).

Данные: `inc/destination-landings.php` → ключ страны.

## Чипы курортов

Подписи — полные русские названия, без операторских аббревиатур. Источник: `zhiraf_ufa_{country}_resort_chips()` в `inc/curated-*-landing.php`.

## Визуал

- Сетка Hero: **7fr / 5fr** (текст / фото) от 992px — `_catalog-destination-landings.scss`, класс `site-main--destination`.
- Фото Hero: открыточный пляж/курорт страны, без «анти-отпуска» (трущобы, промзоны). Файл в `assets/images/`, поле `image` в landing data.
- Иконка визы: `inc/hero-badges.php`, поле `icon_svg` => `passport`.
