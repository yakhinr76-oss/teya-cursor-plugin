# AURA Blog Cover Concept — Жираф

## cover_family

**`editorial_photo`** (primary) — из `blog-cover-family-registry.json`.

## Обоснование

- Совпадает с Globe Trekker **editorial blog** на главной (фото 16:9 + категория).
- B2C travel + экспертные статьи Excalibur: доверие через реалистичные сцены, не иллюстрация SaaS.
- Палитра lock `#FAF8F5` / `#E87A5D` через color grade 15–20%.
- Hero сайта уже photo-collage — серия обложек продолжает тот же «журнальный» язык.

## Fixed vs variable

| Fixed | Variable |
|-------|----------|
| color grade, grain 3%, 16:9, no text/logo | `topic_scene_descriptor` per slug |
| focal rule: subject right third | archetype lighting |

## Secondary families

Нет (`secondary_cover_families: []`).

## Связь с AURADESIGN

Manrope headlines on site; covers **без текста** — заголовок в HTML. No watermark logo.
