# AURA Color Psychology — Жираф (справочно)

> Улучшения из этого файла **не применяются автоматически** при репликации Globe Trekker.

## Текущий lock (референс)

| Цвет | Психология | Роль на сайте |
|------|------------|---------------|
| `#FAF8F5` | тепло, бумага, дом | снижает тревогу перед крупной покупкой |
| `#E87A5D` | энергия без агрессии | CTA «Подобрать тур» |
| `#2B2B2B` | читаемость, серьёзность | длинные тексты блога |

## Опциональные гипотезы (только по запросу клиента)

- Чуть более холодный фон `#F7F5F2` — **не** внедрять без approval (ломает copy-in-copy).
- Secondary green для «успех отправки формы» — можно в system success, не в brand primary.

## Anti-patterns для travel

- Красный как primary (тревога)
- Чёрный hero (luxury mismatch для семейного бренда)
