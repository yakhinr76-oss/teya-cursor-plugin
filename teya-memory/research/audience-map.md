# Audience Map — турагентство «Жираф», Уфа

**Модель бизнеса:** локальное B2C-турагентство (семейный бренд, офис в Уфе). Корпоративный TMC в текущей теме Phase 1 не является ядром; при появлении B2B-направления — отдельный research-цикл.

---

## Сегменты

### 1. Семья с детьми (ядро)

| Поле | Содержание |
|------|------------|
| Кто | Родители 28–45, 1–2 ребёнка, первый или повторный выезд «всё включено» |
| Задача на сайте | Понять, куда из Уфы лететь с детьми и как не ошибиться с отелем/перелётом |
| Боли | Страх «не тот отель», ночные перелёты, питание, медицина, документы на ребёнка |
| Желаемый результат | Спокойный пляжный отдых без сюрпризов в договоре |
| Барьеры | Недоверие к агентствам после негативного опыта; сравнение с Travelata/Level |
| Триггеры | Рекомендация знакомых; офис «можно приехать»; понятный чек-лист |
| Язык | «Без впаривания», «под наш бюджет», «нормальный отель для детей», «вылет из Уфы» |
| Блоки сайта | Квиз (состав «семья»), блог «туры с детьми», FAQ документы, «как работает», контакты |

### 2. Пара без детей / молодые пары

| Поле | Содержание |
|------|------------|
| Кто | 25–40, отпуск 7–10 ночей, Турция/ОАЭ/Египет |
| Задача | Быстро сравнить 2–3 курорта и забронировать без беготни по офисам |
| Боли | Переплата на агрегаторах; непонятно, что входит в AI; страх скрытых доплат |
| Триггеры | Красивый сайт (Globe Trekker-тон); квиз за 2 минуты; мессенджер/звонок |
| Блоки | Hero-коллаж направлений, каталог `/tour/`, статья «всё включено», квиз |

### 3. «Осторожные» / первая заграница

| Поле | Содержание |
|------|------------|
| Кто | 35–55, мало опыта выезда, важны очный контакт и бумажный договор |
| Боли | Паспорт, страховка, что делать при задержке рейса |
| Триггеры | РТА в футере; реквизиты; адрес офиса; история с 2011 года |
| Блоки | `/o-nas/`, `/kontakty/`, блог «как купить тур в Уфе», «документы» |

### 4. Опытные путешественники

| Поле | Содержание |
|------|------------|
| Кто | Уже ездили 3+ раз, ищут нестандарт или конкретный отель |
| Боли | Нехватка экспертизы у «кассира»; хотят менеджера, который «был на курорте» |
| Триггеры | Команда поимённо; честность про минусы отеля |
| Блоки | О нас + команда; блог сравнений (Турция vs Египет); форма с полем «пожелания» в квизе |

### 5. Гибкие по датам / охотники за акцией

| Поле | Содержание |
|------|------------|
| Кто | Готовы лететь в ближайшие 2–4 недели |
| Боли | Боятся пропустить акцию и купить дороже на OTA |
| Триггеры | «Подберём под акции операторов» без обещания «самого дешёвого» |
| Блоки | CTA квиз + телефон; опционально будущий блок «горящие» (**needs_user_fact:** есть ли отдельная витрина) |

### 6. Локальные жители Уфы / соседние города РБ

| Поле | Содержание |
|------|------------|
| Кто | Уфа и пригород; часть — выезд на встречу в офис |
| Боли | «Где надёжное агентство не в ТЦ» |
| Триггеры | ул. Гагарина 74/1; часы Пн–Пт 10–19, Сб 11–15 |
| Блоки | Карта Яндекс; NAP в footer/schema |

## Свод: боли → ответ сайта

| Боль | Ответ (контент/UX) |
|------|-------------------|
| «Обманут с ценой» | Прозрачность в «о нас»; статья про состав пакета; без фейковых «от» |
| «Завалят вариантами» | Ценность: 2–4 варианта под запрос |
| «Не разберусь в документах» | Excalibur чек-лист |
| «Онлайн страшно» | Офис + телефон + договор |
| «А вдруг агентство закроется» | ООО, ИНН/ОГРН, РТА 0012822 |

## Возражения и отработка

| Возражение | Ответ (нейтрально) |
|------------|-------------------|
| «Дешевле на Travelata» | Сравниваем пакет целиком (перелёт, трансфер, страховка, класс номера); менеджер объясняет отличия |
| «Зачем агентство, если есть Coral/Pegas сайт» | Подбор среди нескольких операторов + сопровождение договора в Уфе |
| «Боюсь навязчивых звонков» | Заявка без обязательств; согласие на маркетинг — отдельный чекбокс (38-ФЗ) |
| «Не знаю, куда ехать» | Квиз + статьи-сравнения |
| «Нет времени ехать в офис» | Онлайн-договор / квиз; офис — опция |

## Лексика аудитории (для копирайта)

- **Использовать:** тур из Уфы, пакетный тур, вылет, всё включено / AI / UAI, подбор, менеджер, договор, офис на Гагарина, семейный отдых, курорт, перелёт.
- **Избегать:** «лучшие цены РФ», «№1 в Уфе», «гарантируем визу», жаргон OTA без объяснения.

## Примечание для B2B (если появится корпоратив)

Сейчас **не** выделяем HR/CFO/координатора: в Phase 1 нет страниц корпоративного TMC. При запуске B2B-ветки — отдельные подсекции с болями закупки, отчётности и travel-политики.
