# Offers Map — турагентство «Жираф», Уфа

**Ниша:** розничные пакетные туры и индивидуальный подбор с вылетом из Уфы (B2C).  
**Primary conversion:** заявка / квиз → звонок менеджера → договор.  
**Источники оферов:** тема `zhiraf-ufa`, BUILD-REPORT, публичный `zhiraf-ufa.ru` (маркетинг — только с пометкой needs_user_fact).

## Lead magnet / вход в воронку

| Формат | Описание | Статус |
|--------|----------|--------|
| **Квиз «Подбор тура за 2 минуты»** | 4 шага: состав → месяц → бюджет (диапазоны) → пожелания + контакты | Реализован; лиды → `office@zhiraf-ufa.ru` (BUILD-REPORT) |
| **Чек-листы в блоге** | Документы, «всё включено», дети | Контент-магниты без скачиваемого PDF — CTA «задать вопрос менеджеру» |

Диапазоны бюджета в квизе (из темы): до 80k; 80–120k; 120–180k; выше 180k ₽ **на человека** — использовать как квалификацию лида, не как обещание цены.

## Что обещать нельзя (юридическое + anti-haltura)

- Фиксированные цены «от … ₽» и «дешевле всех» без привязки к дате и оператору.
- «24/7 поддержка в отеле» — только если подтверждён контракт с оператором (**needs_user_fact**).
- Выдуманные отзывы, рейтинги, AggregateRating в schema.
- «Рассрочка 0%» / банки-партнёры — без актуального списка от клиента.
- Гарантия визы, погоды, отсутствия форс-мажора.
- Копирование маркетинговых цифр с текущего `zhiraf-ufa.ru` (782 клиента, 16 экспертов и т.д.) без подтверждения.

## Факты, нужные от пользователя (для усиления оферов)

1. Список туроператоров, с которыми работает агентство (для блока доверия).
2. Актуальные условия рассрочки / банки.
3. Реальные отзывы: ВК, Яндекс.Карты, 2ГИС — URL и разрешение на публикацию.
4. ID Яндекс.Метрики для прода.
5. Подтверждение: ведётся ли email-рассылка и кто отвечает на `office@zhiraf-ufa.ru`.
6. Приоритет направлений на сезон (какие 2–3 крутить в hero).
7. Есть ли групповые / корпоративные туры как отдельная услуга (сейчас в теме — массовый B2C).
