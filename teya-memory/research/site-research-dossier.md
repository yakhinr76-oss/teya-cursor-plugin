## 1. Краткое резюме

**«Жираф»** — семейное турагентство в Уфе (ООО «Жираф», РТА 0012822), работает с **апреля 2011**, офис на **ул. Гагарина, 74/1**. Продаёт **пакетные туры с вылетом из Уфы** (Турция, ОАЭ, Египет, Таиланд, Вьетнам; в каталоге упомянута Россия) через **персональный подбор**, а не через безличный прайс-агрегатор.

**Стратегия сайта Phase 1:** премиальный визуал по референсу **Globe Trekker** (молочный фон, терракотовый акцент, hero-коллаж, табы направлений), конверсия через **квиз «Подобрать тур»** и телефон, экспертность через **блог Excalibur**, доверие через **юрфакты и офис**, без фейковых отзывов и цен.

**Конкурентное поле Уфы:** сильные сети (Coral, Pegas), локальные офисы (Эль-Вояж, Желтый чемодан) и агрегаторы (Viasun, Нано Тревел). Дифференциатор Жираф — **локальный семейный сервис + честный подбор**, а не «самая низкая цена на экране».

**Главные пробелы данных:** подтверждённые отзывы, список операторов, условия рассрочки, Метрика, синхронизация маркетинговых цифр с действующего zhiraf-ufa.ru.

## 2. Тема сайта и рынок

### Что продвигается

- Розничные **туры / путёвки** с вылетом из **Уфы**.
- **Индивидуальный подбор** (менеджер, договор, офис).
- Контент-поддержка решения: блог, FAQ, квиз-квалификация лида.

### Рынок и контекст

- **География спроса:** Уфа и Республика Башкортостан; часть клиентов сравнивает вылеты через Москву/Казань (упоминается на старом сайте — не обещать без уточнения).
- **Формат продукта:** пакетный тур (перелёт + отель + трансфер + страховка по пакету оператора); доп. услуги — по запросу (**needs_user_fact:** визы, только билеты, корпоратив).
- **Каналы конкуренции:** OTA (Travelata, Level.Travel), сайты туроператоров, агрегаторы, франшизы в ТЦ.

### Сезонность и тренды (общеотраслевые)

| Период | Типичный спрос (Уфа/РФ) | Релевантные направления в теме |
|--------|-------------------------|--------------------------------|
| Январь–март | Пляж «зимой» | ОАЭ, Египет, Таиланд |
| Апрель–май | Раннее бронирование / майские | Турция, Египет |
| Июнь–август | Семьи, школьные каникулы | Турция, ОАЭ, внутренний туризм |
| Сентябрь–октябрь | «Бархат», свадьбы | Турция, ОАЭ |
| Ноябрь–декабрь | Новый год, раннее бронирование | ОАЭ, Таиланд, горнолыжные (не в каталоге темы) |

Тренды 2025–2026 для копирайта (без цифр Жираф): рост **самостоятельного поиска** онлайн → нужны квиз и экспертные статьи; важность **прозрачности состава пакета** (AI/UAI); доверие к **локальному офису** после волатильности рынка.

### Ограничения и риски обещаний

- Не гарантировать **минимальную цену** и **наличие мест** без привязки к оператору и дате.
- Не обещать **визу** и **погоду**.
- **Форс-мажоры** и отмены рейсов — зона ответственности оператора/страховки; агентство сопровождает, но не «гарантирует отдых».
- На действующем zhiraf-ufa.ru есть **устаревшие контакты** — не тиражировать.

## 3. Продукт / услуги / личность / бренд

### Продуктовая линейка (подтверждённая темой + каталог)

| Услуга | Статус в Phase 1 |
|--------|------------------|
| Подбор пакетного тура из Уфы | ✅ ядро |
| Направления: Турция, ОАЭ, Египет, Таиланд, Вьетнам | ✅ |
| Отдых по России | ✅ упоминание в `/tour/` |
| Горящие туры | ⚠️ на старом сайте есть; в теме нет витрины цен |
| VIP / круизы / свадебные / гастро | ⚠️ только на zhiraf-ufa.ru — **needs_user_fact** |
| Страхование, рассрочка | ⚠️ статья в блоге; детали у клиента |

### Ценность и отличие (рабочее позиционирование)

1. **Семейный бренд** с историей с 2011, не безликий агрегатор.
2. **Честный подбор** — «как для друзей», без давления (тема + live-сайт).
3. **Уважение к времени** — не заваливать десятками нерелевантных отелей.
4. **Локальность** — офис в Уфе, можно приехать.
5. **Юридическая прозрачность** — ООО, реквизиты, РТА.

### Личность бренда / команда

- Основатели: **Зульфия, Ксения** (2011).
- Расширение команды (2014): **Лия, Алина, Рафаэль** (история на «О нас»).
- Публичные роли в теме: **Рафаэль** (директор), **Зульфия**, **Альфия**, **Гульнара**.

Тон: тёплый, экспертный, без панибратства и без «продажного крика» агрегаторов.

### Доказательства (только подтверждённые)

- Реквизиты, РТА, адрес, телефон, email — см. fact-bank.
- Блог-статьи с практическими чек-листами.
- VK: `vk.com/zhiraf_ufa`.

### Что нельзя выдумывать

- Отзывы, рейтинги, кейсы с именами.
- Цены, скидки, «экономия до X%».
- Число клиентов, награды, «лидер рынка Уфы».
- Состав команды beyond fact-bank.

## 10. FAQ и answer-блоки

Рекомендуемые вопросы (ответы — нейтральные, без цен):

1. **Как купить тур через «Жираф»?** — Заявка/квиз → консультация → договор → оплата по правилам оператора.
2. **Сколько стоит тур из Уфы?** — Зависит от дат, отеля и оператора; менеджер считает пакет под запрос (без «от» на сайте до политики клиента).
3. **Что входит в «всё включено»?** — Ссылка на статью; перелёт, проживание, питание по коду AI/UAI и т.д.
4. **Какие документы нужны?** — Ссылка на чек-лист; не юрконсультация.
5. **Можно ли в рассрочку?** — Уточняем у клиента актуальные банки (**needs_user_fact**).
6. **Работаете ли с детьми?** — Да, подбор с учётом состава семьи (квиз).
7. **Где офис и часы работы?** — Гагарина 74/1; часы из fact-bank.
8. **Чем вы отличаетесь от сайта оператора?** — Подбор среди операторов + сопровождение в Уфе (уточнить список операторов).
9. **Куда лететь из Уфы зимой/летом?** — Общеотраслевые подсказки + каталог (без гарантий погоды).
10. **Как оставить отзыв?** — После поездки — VK/карты (**needs_user_fact** URL карт).
