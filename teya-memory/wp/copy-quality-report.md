## 2. Ключевые фактологические параметры по направлениям

### Страны (Destination Hubs)

1. **Турция (`/tour/turciya/`)**:
   - Время перелёта: ~4.5–5 часов из Уфы (Анталья).
   - Сезонность: май–октябрь (вода +21...+28°C), июль–август пик (+34...+38°C), сентябрь–октябрь бархатный (+27...+30°C, вода +25...+27°C).
   - Виза: безвизовый въезд для граждан РФ до 60 дней непрерывно (до 90 дней в полугодии).
   - Курорты: Анталья, Кемер, Аланья, Сиде, Белек.
   - Отели: All Inclusive, Ultra All Inclusive, детские клубы, аквапарки, adults only.

2. **ОАЭ (`/tour/oae/`)**:
   - Время перелёта: ~5 часов из Уфы (Дубай / Шарджа / Абу-Даби).
   - Сезонность: октябрь–апрель (+26...+32°C, вода +24...+28°C).
   - Виза: бесплатная туристическая виза по прибытии (30 дней).
   - Эмираты: Дубай, Рас-эль-Хайма (All Inclusive у моря), Шарджа, Абу-Даби, Фуджейра (Оманский залив).
   - Отели: городские и пляжные, завтраки (BB) vs All Inclusive (RAK/Фуджейра), туристический налог (Tourism Dirham).

3. **Египет (`/tour/egipet/`)**:
   - Время перелёта: ~5–5.5 часов из Уфы (Хургада / Шарм-эль-Шейх).
   - Сезонность: круглогодично, лучший период октябрь–май (+27...+32°C, вода +24...+27°C).
   - Виза: Хургада — виза по прибытии $25; Шарм-эль-Шейх — бесплатный «синайский штамп» (Sinai Only) до 15 дней.
   - Курорты и бухты: Хургада (песчаные пологие пляжи), Шарм-эль-Шейх (бухты Наама Бей, Набк, Рас-Ум-Сид, Шаркс Бей с коралловыми рифами).
   - Отели: All Inclusive, первые береговые линии, подогреваемые бассейны в зимний период.

4. **Таиланд (`/tour/tailand/`)**:
   - Время перелёта: ~8.5–9 часов (прямой чартер) / от 11 часов (со стыковкой).
   - Сезонность: ноябрь–апрель высокий сезон (вода Андаманского моря и Сиамского залива +28...+30°C).
   - Виза: безвизовый штамп для граждан РФ (30–60 дней в зависимости от сезонных постановлений).
   - Курорты: Пхукет (Ката, Карон, Патонг, Банг Тао), Паттайя (Джомитьен, Вонгамат), Самуи, Краби, Чанг.
   - Отели: концепция BB (завтраки), развитая ресторанная и экскурсионная инфраструктура.

5. **Вьетнам (`/tour/vietnam/`)**:
   - Время перелёта: ~9–9.5 часов (прямой рейс в Камрань) / от 12 часов (стыковочные маршруты).
   - Сезонность: Нячанг — февраль–август (+28...+32°C); Фукуок — ноябрь–апрель (+28...+30°C).
   - Виза: безвизовый въезд для граждан РФ до 45 дней.
   - Курорты: Нячанг (городские пляжи, остров Винперл, грязелечебницы), Фукуок (пляжи Лонг Бич, Бай Сао, сафари Vinpearl Safari).
   - Отели: городские отели (BB), курортные островные комплексы (AI / FB), спа-резорты.
