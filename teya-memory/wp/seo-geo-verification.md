## 5. Проверка индексации и Staging-изоляции

1. **Staging Host Detection (`b2b-tour.ru`):**
   - Функция `zhiraf_ufa_is_staging_host()` проверяет `HTTP_HOST`.
   - При совпадении с `b2b-tour.ru`:
     - Отправляется HTTP-заголовок `X-Robots-Tag: noindex, nofollow` через хук `send_headers`.
     - В `<head>` выводится `<meta name="robots" content="noindex, nofollow" />`.
     - Фильтр `robots_txt` отдает `User-agent: *\nDisallow: /\n`.
2. **Production Host (`zhiraf-ufa.ru`):**
   - В `<head>` выводится `<meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large, max-video-preview:-1" />`.
   - Канонические теги `link rel="canonical"` принудительно нормализуются к production URL `https://zhiraf-ufa.ru/...`.
